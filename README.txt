ISRA BIRTHDAY GIFT V2 — PREMIUM THEME

Included files:
- index.html: responsive lavender/pink birthday website, animated balloon shapes, cake, notes, gallery, dua and music toggle
- assets/isra_car_cartoon.jpg
- assets/isra_teddy_cartoon.jpg
- assets/happy-birthday-to-you.mp3: bundled short instrumental birthday melody

GitHub Pages setup:
1. Create a new PUBLIC repository named Isra-Birthday-Gift-V2.
2. Upload index.html to the repository root.
3. Upload the complete assets folder, preserving the filenames.
4. Go to Settings > Pages.
5. Select Deploy from a branch, branch main, folder /(root), then Save.

Music note:
The included MP3 is an instrumental melody, not a female vocal recording. The music toggle starts playback after the visitor interacts with the site. If you later create/download a licensed female-singing Happy Birthday MP3, name it happy-birthday-to-you.mp3 and replace the file in assets.
